# Proposal: Property Management

## Goal
Manage rural properties involved in forest management projects. Ensure compliance with environmental regulations (CAR) and provide a spatial overview of property boundaries.

## Context
Properties are the physical locations where projects are executed. A single property can host multiple inventories and projects over time.

## Features
- **Property CRUD**: Register and update property details including CAR number, area in hectares, and municipality.
- **Media Management**: Upload and track photos for each property.
- **Inventory Access**: Entry point for managing tree inventories associated with the property.
- **Spatial Awareness**: Visualize property location and boundaries via Integrated Maps.
- **AI-Powered Validation**: Assistance for correcting or validating property metadata (e.g., CAR format).

## Success Criteria
- Property data is organized and easily accessible for project planning.
- Photo documentation is correctly linked and displayed.
- Seamless transition between property management and tree inventory tools.
