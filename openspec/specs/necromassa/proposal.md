# Proposal: Necromassa Licensing

## Goal
Streamline the licensing process for "necromassa" (fallen trees/biomass) by providing technical estimation and fraud detection tools for field data analysis.

## Context
Necromassa licensing allows for the sustainable removal of naturally fallen trees. It requires strict evidence that the tree was not illegally felled (hence the root evidence requirement).

## Features
- **Volume Estimation**: Automated calculation of wood volume based on Circumference at Breast Height (CAP) and tree height, adjusted by species-specific form factors.
- **Fraud Detection**: Automatic alerts for coordinates outside the Amazon region and verification of root exposure to ensure the tree fell naturally.
- **Audit Workflow**: Dashboard for reviewing requests and approving them for submission to environmental agencies (IPAAM).
- **Species Mapping**: Integrated database for mapping common names to scientific names and growth parameters.

## Success Criteria
- Accurate volume estimation for IPAAM licensing.
- Reduced risk of fraudulent claims through automated coordinate and evidence checks.
- Efficient review process through a dedicated audit drawer with map integration.
