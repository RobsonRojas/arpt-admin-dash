## Purpose
Transform raw forestry data into strategic insights through AI-driven prediction and visual analytics.

## Requirements

### Requirement: Yield Prediction Analytics
The system MUST generate comparisons between predicted and realized forest growth.

#### Scenario: Visualizing Growth Trends
- **WHEN** a user opens the Forest Intelligence dashboard
- **THEN** the system must render Bar/Pie charts reflecting the current inventory metrics

### Requirement: AI Insight Generation
The system SHALL use AI to interpret data trends and provide strategic recommendations.

#### Scenario: Generating Strategic Insights
- **WHEN** analytics are refreshed
- **THEN** the system must generate a natural language summary of the forest state using Gemini
