# Proposal: Media Manager

## Goal
Centralize the management of all digital assets (photos, certificates, technical documents) used across the platform.

## Context
A forest project generates thousands of photos and documents. The Media Manager provides a unified interface for administrators to upload, search, and retrieve these assets for use in projects, inventory, and user storytelling.

## Features
- **Centralized Gallery**: View all uploaded files in a responsive grid or list view.
- **Multipart Upload Engine**: Support for uploading high-resolution photos, PDFs, and videos.
- **Unified URL Access**: Automatic generation of public links for integration into other modules (e.g., Tree Photos).
- **Asset Search**: Quick filtering by filename to find specific documents or images.
- **Integrated Preview**: On-page visualization of images and document metadata before use.
- **Clipboard Integration**: One-click copying of asset URLs to simplify manual data entry workflows.

## Success Criteria
- Reliable upload and storage of technical documents and field photos.
- Fast retrieval of assets through the search interface.
- Consistent URL patterns for assets across the entire application.
